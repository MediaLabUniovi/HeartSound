# Estetostrónico
This is a project in collaboration with the Medical University of Sofia to develop a device that simulates the sound heard through a stethoscope on different parts of the body and from various types of hearts.

## Components

| Component              | Description                                             | Quantity |
|------------------------|---------------------------------------------------------|:--------:|
| ESP32 Dev Module       | 32-bit microcontroller with Wi-Fi and Bluetooth         |     1    |
| DFRobot DFPlayer Mini  | MP3 audio playback module with SD card reader           |     1    |
| Speakers               | 2 W, 8 Ω passive speakers for audio output              |     2    |
| Buttons                | Momentary push-buttons (to GND, using internal pull-up) |     3    |
